# Proyecto: Limpieza de datos con Programación Orientada a Objetos (POO)
Análisis y limpieza de una encuesta socioeconómica usando Python y una clase personalizada.

## Descripción
Este proyecto implementa un sistema de limpieza de datos para una encuesta socioeconómica con 50 registros válidos.
Se utiliza Programación Orientada a Objetos (POO) para crear una clase "Limpiador" que:
- Normaliza textos (ciudades).
- Estandariza géneros.
- Convierte y valida ingresos económicos.
- Convierte y valida edades.
- Elimina registros duplicados e inválidos.
- Genera un resumen descriptivo del dataset limpio.

## Objetivos
- Diagnosticar errores en datos reales.
- Implementar métodos de limpieza usando POO.
- Validar datos contra criterios específicos.
- Generar estadísticas descriptivas.
